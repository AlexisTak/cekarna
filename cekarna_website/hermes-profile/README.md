# Profil Hermes Cekarna

Copier `SOUL.md` dans le dossier personnel de l’instance Hermes dédiée à Cekarna :

- emplacement habituel : `~/.hermes/SOUL.md` ;
- avec un répertoire personnalisé : `$HERMES_HOME/SOUL.md`.

Hermes ne charge pas ce fichier depuis le dossier du projet. Redémarrer la session Hermes après la copie. Les règles techniques et le contexte du dépôt restent dans le fichier `AGENTS.md` à la racine du projet.
